        Try the demo

        An openly licensed demo: ten captioned lectures from MIT OpenCourseWare 6.046J Introduction to Algorithms (Fall 2005), CC BY-NC-SA 4.0. No HKU access or API key needed.

        Index a Panopto folder

        1. Open your course's Panopto folder in this browser tab (through Moodle if that is how you normally sign in).
        2. Click Index this course. Chrome will ask once to let Rewind read Panopto pages.

        Rewind reads only the captions you can already see, stores them on this device, and never downloads audio or video. Ask your lecturer before indexing course material; seeing a recording is not permission to copy its captions.

        Videos not indexed

          Local search model

          Paraphrased and Chinese questions need a multilingual embedding model that runs on your device. It is downloaded once (about 120 MB) and then works offline. Without it Rewind still does keyword search.

          Model not loaded.

          Your data

          Captions, search indexes and settings are stored only in this browser. Rewind collects no usage analytics and sends nothing to any server. Opening a video uses the normal Panopto or YouTube page.

          What Rewind does not do

          • It does not solve assignment, quiz or exam questions.
          • It does not summarise whole lectures.
          • It does not bypass Panopto access controls or handle passwords.
          • It does not share captions or indexes with anyone.

          LLM query rewriting and Whisper transcription from the proposal are not part of this version.
