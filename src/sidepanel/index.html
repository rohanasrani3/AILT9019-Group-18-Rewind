          Index a Panopto folder

          1. Open your course's Panopto folder in this browser tab (through Moodle if that is how you normally sign in).
          2. Click Index this course. Chrome will ask once to let Rewind read Panopto pages.

          Rewind reads only the captions you can already see, stores them on this device, and never downloads audio or video. Ask your lecturer before indexing course material; seeing a recording is not permission to copy its captions.

            Local search model

            Paraphrased and Chinese questions need a multilingual embedding model that runs on your device. It is downloaded once (about 120 MB) and then works offline. Without it Rewind still does keyword search.

            Model not loaded.

            Optional: AI query help (off by default)

            With your own API key, an external language model can (1) rewrite your question into lecture-style English search terms and (2) give each result a one-line label. Local search always runs too; if the API fails, you still get the local results. It never sees assessment requests and is instructed never to answer or solve anything.

            Get a key · usage is billed to your own account by the provider.

            What leaves your device

            Excerpts that look personal (emails, phone numbers, student IDs, names) are never sent. For Panopto courses, labels stay off unless you tick “external processing permitted” for that course in the Courses tab. The provider's data policy applies to what is sent.

            Exact request preview (for your last question):

            Run a search first to see exactly what would be sent.

            Your data

            Captions, search indexes and settings are stored only in this browser. Rewind collects no usage analytics. Nothing is sent anywhere unless you turn on the optional AI query help above. Opening a video uses the normal Panopto or YouTube page.

            What Rewind does not do

            • It does not solve assignment, quiz or exam questions.
            • It does not summarise whole lectures.
            • It does not bypass Panopto access controls or handle passwords.
            • It does not share captions or indexes with anyone.

            Local Whisper transcription is a separate command-line tool for licensed media only (see the README); it is not part of the extension.
